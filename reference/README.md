# 📚 Reference Directory (Third-Party External Mods)

Direktori ini khusus menyimpan **mod acuan pihak ketiga (external / third-party references)** yang didekompilasi atau diekstrak untuk studi implementasi arsitektur mekanik Minecraft.

> [!IMPORTANT]
> Seluruh isi direktori ini bersifat **read-only** dan **diabaikan oleh Git** (`.gitignore: reference/*`) agar ukuran repository tidak membengkak oleh file binary/JAR besar.
> Aset master buatan proyek sendiri (`asset_pack`, master `.bbmodel`, tekstur, suara, dan animasi) dipusatkan di `art-source/`.

---

## 🗂️ Daftar Mod Acuan Pihak Ketiga:

1. **Epic Fight Ecosystem:**
   - `epic-fight-21.17.3.1-mc1.21.1-neoforge/` & `.zip`: Acuan sistem animasi tempur, kombo senjata, dan pose layer.
   - `epicfight-skilltree-neoforge-21.3.3-1.21.1/` & `.zip`: Acuan struktur tree percabangan skill.
   - `EFMCompat 2.0/` & `.zip`: Acuan kompatibilitas animasi pihak ketiga.
   - `sword_soaring-21.14.2.5-mc1.21.1-neoforge/` & `.zip`: Acuan animasi pedang melayang & mobilitas.

2. **Avatar Elements & Bending Reference:**
   - `avatar-legend-reforged-1.3.0/` & `.zip`: Acuan implementasi bending klasik dan efek partikel.
   - `avatarmod-0.3.0/` & `.zip`: Acuan bending Fabric/Forge awal.
   - `Avatar-Addon-1.3.2-Beta/` & `.zip`: Acuan implementasi bending Bedrock / Datapack.

3. **Client Utilities & HUD:**
   - `RPG-HUD 3.13-EXTRACT_ME/` & `.zip`: Acuan layout HUD gaya RPG (status bar, widget overlay).
   - `Essential_1-5-2_fabric_1-21-1/` & `.jar`: Acuan rendering kosmetik, UI modern, dan integrasi Fabric.
   - `WOLegendaryMonsters-1.1.0-forge-1.20.1/` & `.zip`: Acuan entity rendering & hitbox kustom.
